# IT3012 - Search Algorithms in Pac-Man

Implementation of search algorithms and heuristic-based problem solving for the Pac-Man project.

## Requirements

- Python 3.11
- Conda
- NumPy
- Matplotlib

## Setup

```bash
conda create -n cs188 python=3.11
conda activate cs188
pip install numpy matplotlib
```

## Running the Project
```bash
python pacman.py
```
